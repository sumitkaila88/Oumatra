# Production brand assets

This directory reserves the public asset architecture for approved OUMATRA masters.

- `logo/` — final production logo files and approved variants
- `favicon/` — final favicon and app-icon artwork
- `social/` — approved social avatar and sharing artwork
- `reference/` — provenance notes for non-production visual references

Do not add traced, generated, redrawn, or substitute logo artwork. Every production asset should arrive with an explicit approval status, source, format, and usage guidance. The conceptual brand-kit image is not a production master and is not served by the website.
