# Production brand assets

This directory contains the approved v1 production asset system for OUMATRA.

- `logo/` — final production logo files and approved variants
- `favicon/` — final favicon and app-icon artwork
- `social/` — approved social avatar and sharing artwork
- `reference/` — provenance notes for non-production visual references

Do not add auto-traced, generated, or substitute logo artwork. Every future asset must have explicit approval status, source, format, and usage guidance. See `docs/LOGO_SPECIFICATION.md` and `docs/BRAND_ASSET_GUIDELINES.md` before use.
